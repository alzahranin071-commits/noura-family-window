# نافذة الأسرة على Cloudflare: الإعداد

الإعداد مجاني ودون بطاقة بنكية، ويتم مرة واحدة من جهاز حاسب. لا تحتاجين كتابة أي كود.

1. **أنشئي حسابين مجانيين:** في **cloudflare.com** (Sign up) وفي **github.com**.
2. **ارفعي المشروع إلى GitHub:**
   - أنشئي مستودعًا جديدًا (New repository) خاصًا (Private) باسم `nafidhat-alusra`.
   - اضغطي **uploading an existing file**.
   - فكّي ضغط الملف المضغوط، واسحبي كل محتوياته إلى الصفحة **في عملية واحدة**، ثم اضغطي **Commit changes**.
3. **أنشئي قاعدة البيانات:**
   - في Cloudflare: **Storage & Databases** ← **D1** ← **Create database**.
   - الاسم: `nafidha-db` ← **Create**.
   - انسخي الرقم الظاهر بجانب **Database ID**.
4. **اربطي قاعدة البيانات بالمشروع:**
   - في GitHub افتحي ملف `wrangler.jsonc` واضغطي ✏️ (تعديل).
   - ضعي الرقم الذي نسختِه مكان العبارة `ضعي-رقم-قاعدة-البيانات-هنا`، مع إبقاء علامتي التنصيص.
   - اضغطي **Commit changes**.
5. **انشري الموقع:**
   - في Cloudflare: **Workers & Pages** ← **Create** ← **Import a repository** ← اختاري `nafidhat-alusra`.
   - اسم المشروع يجب أن يكون **`noura-family-window`** تمامًا.
   - اضغطي **Deploy**.
6. **ضعي كلمة مرور الإدارة:**
   - افتحي المشروع ← **Settings** ← **Variables and Secrets** ← **Add**.
   - النوع: **Secret**. الاسم: `ADMIN_PASSWORD`. القيمة: كلمة مرور من ١٠ خانات أو أكثر.
   - اضغطي **Deploy**.
   - لا ترسلي كلمة المرور لأي أحد.
7. **ادخلي إلى لوحة الإدارة:**
   - افتحي `https://noura-family-window.<اسم-حسابك>.workers.dev/admin`. الرابط الكامل يظهر في صفحة المشروع.
   - إن كان لديكِ محتوى قديم بصيغة JSON: لوحة التحكم ← «النشر والنسخ» ← «استيراد» ← ثم «نشر».

**تحويل الرابط القديم (اختياري):**
- افتحي ملف `old-link-redirect/_redirects` على جهازك، وضعي رابطك الجديد مكان `YOUR-NAME`.
- في Netlify افتحي موقعك القديم ← **Deploys**، واسحبي مجلد `old-link-redirect` إلى المربع.
- بعدها يُحوَّل كل من يفتح الرابط القديم إلى الموقع الجديد تلقائيًا.

**الاستخدام اليومي:**
- افتحي `/admin` من الجوال أو الحاسب.
- عدّلي ما تريدين؛ يُحفظ تلقائيًا كمسودة.
- اضغطي **معاينة** ثم **نشر**.
- لا حاجة لـ GitHub أو Claude بعد الإعداد.

**الحدود المجانية:** ١٠٠ ألف طلب يوميًا، و٥ غيغابايت تخزين، والحد الأقصى للملف ٤ ميغابايت. هذه الحدود كافية لموقع مدرسي.

**إذا ظهرت رسالة:**
- «قاعدة البيانات غير مربوطة»: راجعي الخطوة ٤.
- «لم تُضبط كلمة مرور الإدارة»: راجعي الخطوة ٦.
- فشل النشر في الخطوة ٥: تأكدي أن اسم المشروع `noura-family-window`.
